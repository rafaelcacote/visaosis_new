## 🚀 Hot Reload / Atualização Automática

O projeto está configurado com **Vite** para atualização automática do navegador quando você modificar arquivos.

### Como usar:

1. **Inicie o servidor Laravel** (em um terminal):
   ```bash
   php artisan serve
   ```

2. **Inicie o servidor Vite** (em outro terminal):
   ```bash
   npm run dev
   ```

3. **Acesse sua aplicação** no navegador (geralmente `http://localhost:8000`)

Agora, quando você modificar qualquer arquivo em:
- `resources/views/**` (arquivos Blade)
- `app/**` (controllers, models, etc.)
- `routes/**` (rotas)
- `resources/css/**` (CSS)
- `resources/js/**` (JavaScript)

O navegador **atualizará automaticamente** sem precisar recarregar manualmente! 🎉

### Notas:
- Mantenha ambos os servidores rodando durante o desenvolvimento
- O Vite roda na porta `5173` por padrão
- Mudanças em arquivos PHP/Blade causam um reload completo da página
- Mudanças em CSS/JS são aplicadas instantaneamente (HMR - Hot Module Replacement)

### Solução de Problemas:

**Erro de permissão ao executar `npm run dev`:**
Se você encontrar erros de permissão (Permission denied), execute:
```bash
./fix-permissions.sh
```

Ou manualmente:
```bash
chmod +x node_modules/.bin/*
chmod +x node_modules/@esbuild/linux-x64/bin/esbuild
chmod +x node_modules/esbuild/bin/esbuild
find node_modules -type f -name "*.node" -exec chmod +x {} \;
```

## About Laravel

Laravel is a web application framework with expressive, elegant syntax. We believe development must be an enjoyable and creative experience to be truly fulfilling. Laravel takes the pain out of development by easing common tasks used in many web projects, such as:

- [Simple, fast routing engine](https://laravel.com/docs/routing).
- [Powerful dependency injection container](https://laravel.com/docs/container).
- Multiple back-ends for [session](https://laravel.com/docs/session) and [cache](https://laravel.com/docs/cache) storage.
- Expressive, intuitive [database ORM](https://laravel.com/docs/eloquent).
- Database agnostic [schema migrations](https://laravel.com/docs/migrations).
- [Robust background job processing](https://laravel.com/docs/queues).
- [Real-time event broadcasting](https://laravel.com/docs/broadcasting).

Laravel is accessible, powerful, and provides tools required for large, robust applications.
